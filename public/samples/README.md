# Samples Directory

Place real fabric defect photos here for the 4 sample images.

## Expected filenames

| File | Description |
|------|-------------|
| `sample1.jpg` | Woven fabric with visible stain and float defect |
| `sample2.jpg` | Denim with slub cluster and broken warp end |
| `sample3.jpg` | White shirting with weft bar running across full width |
| `sample4.jpg` | Jersey knit with run hole and crease mark |

## Sourcing suggestions

- **Open source**: [DTD (Defect Textile Dataset)](https://zenodo.org/record/4751356) — free for research
- **TILDA dataset** — industrial textile images
- **Your own mill photos** — best for the target customer

## Requirements

- Minimum 600×400 px, maximum 10 MB
- Good even lighting, fabric fills most of the frame
- Clear, sharp focus (the AI needs to see texture detail)
- Label which image is which before swapping in

> The app works without these files in Demo Mode.
> Placeholder canvases are generated automatically if the files are missing.
